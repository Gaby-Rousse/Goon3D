# Gameplay

Play solo or in coop online (there's 2 character but the code should work with an infinite number of player, tested with 4.) and beat enemies.

The game is poorly balanced, good luck.

If you're in COOP you can revive your teammate by kicking them (you will need it trust me)

# Multiplayer

Multiplayer has been tested in LAN only

For WAN (using your public IP)
you would probably need to port forward the following port on your router: **7777**

Multiplayer only tested up to 4, should work with infinite player tho.

# Inputs

## Keyboard & Mouse

Left Click: Punch

Right Click: Kick

Spacebar: Jump

Spacebar while strafing: Dash

Shift: Strafe

Escape: Pause (allow you to change the music currently playing)

## Controller (XBOX)

X: Punch

Y: Kick

A: Jump

A while strafing: Dash

Left Trigger: Strafe

Left Shoulder: Play previous music (paused)

Right Shoulder: Play next music (paused)

Start Button: Pause (allow you to change the music currently playing)

# 3D Models

The main characters are Kyoko and Misako and comes from the game [River City Girls](https://wayforward.com/games/river-city-girls). I modeled the character myself in blender.

The other models, textures, animations, skybox all comes from the internet.
